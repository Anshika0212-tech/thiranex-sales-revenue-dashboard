# Thiranex Sales & Revenue Analysis Dashboard

## Project Overview

This project focuses on analyzing sales and revenue performance through an interactive dashboard.

The dashboard brings together key performance indicators, sales trends, program performance, acquisition channels, regional performance, payment status and completion analysis in one place.

## Objectives

- Analyze overall sales and revenue performance
- Track important business KPIs
- Identify high-performing programs
- Compare acquisition channels
- Analyze regional performance
- Monitor payment and completion status
- Generate useful business insights
- Present the analysis through an interactive dashboard

## Dashboard Features

### KPI Tracking

The dashboard tracks:

- Net Revenue
- Total Orders
- Average Order Value
- Paid Orders
- Refund Value
- Completed Orders
- Paid Order Rate
- Refund Rate
- Completion Rate

### Data Visualization

The dashboard includes:

- Monthly Revenue Trend
- Revenue by Program
- Revenue by Acquisition Channel
- Revenue by Region
- Program Performance Analysis
- KPI Performance Analysis

### Interactive Filters

The dashboard can be filtered by:

- Program
- Acquisition Channel
- Region
- State
- Payment Status
- Completion Status

These filters make it easier to explore different parts of the sales and revenue data.

## Business Insights

The dashboard helps identify:

- Top-performing programs
- Strongest acquisition channels
- Highest-performing regions
- Monthly revenue performance
- Payment and completion patterns
- Areas that may require further business attention
